# CodexTouchBar 0.2.4 · Claude 使用说明

这是在原 CodexTouchBar 内加入 Claude Desktop 支持的版本。切换到 Claude 时显示 Claude 数据，切回 Codex 时显示 Codex 数据。当前版本为 0.2.4（build 17）。

## 使用前

1. 在 Claude Code 内运行 `/login`，使用与 Claude Mac 桌面版相同的账号。凭据过期时需重新登录。
2. 从新版菜单选择「连接 Claude 用量…」，按需允许 macOS 钥匙串访问。若仍提示凭据不可用，先完成这项钥匙串授权；授权成功后若凭据已过期，再在 Claude Code 中重新运行 `/login`。
3. 从菜单选择「启用 Claude 侧栏任务访问」，在系统设置 → 隐私与安全性 → 辅助功能中允许 CodexTouchBar。Claude 的侧栏需要展开。

## 显示和刷新

- Claude 在前台时，任务列表每 5 秒更新，用量每 60 秒请求一次。
- 重新切回 Claude，距离上次请求满 30 秒时刷新；后台停止自动轮询。
- 点按额度按钮可立即刷新。请求失败会自动延长重试间隔，最长 15 分钟。
- `余`表示剩余比例；Claude 设置页显示的通常是已用比例，两者相加为 100%。
- `旧`表示历史数据或刷新失败后保留的数据。实际采样时间和来源显示在预览窗口及鼠标提示中，不能当作实时额度。
- 桌面历史由 Claude 自己更新，观察到约 15 分钟一次；本软件提高读取频率不能让这份历史实时化。
- 同时显示最多 6 项正在进行的任务。侧栏任务优先；只有 Running、Working、工具使用、Awaiting input、Awaiting answer 或 Approval required 等活动状态会显示。Idle、Done、未知状态和历史 Cowork 元数据不会显示；没有活动任务时显示「等待任务」。
- Code / Cowork 的任务按钮可跳转到对应页面；不会将缺少可靠状态的任务显示为正在运行的计时器。

## 验证与限制

- 核心检查、生产构建、Info.plist 和本地 ad-hoc 签名校验通过；未做 Apple 公证。
- 无活动任务时的预览已验证，只显示「等待任务」；当前有两个 Running 任务时，0.2.4 构建版预览显示两个活动任务按钮，Idle 条目未计入。
- 0.2.4 安装版已核对版本、签名及构建文件一致性。已检查安装版版本、签名及构建文件一致性。用户完成重新登录和钥匙串授权后反馈可用。
- 普通聊天、Code、Cowork 的各类活动状态与实体 Touch Bar 点按仍需随实际使用持续验证。
- 切换到菜单或预览时，Claude 任务快照保持更新。
- 辅助功能授权与钥匙串授权相互独立。非交互读取被拒绝时，请通过「连接 Claude 用量…」触发系统授权；不要仅重复登录。

用量接口、Claude 元数据和 Touch Bar 展示部分依赖未公开的内部接口。若后续 Claude/macOS 更新改变接口，可能需要兼容性修复。登录凭据仅在内存中用于请求 Anthropic 用量接口，不写入本项目，不读取聊天正文或会话 transcript 文件。
